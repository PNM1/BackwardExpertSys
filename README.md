# Помощник по ремонту автомобилей

Интеллектуальная экспертная система на базе платформы **.NET 10.0** и фреймворка **WPF (C#)**, предназначенная для автоматизированной диагностики неисправностей транспортных средств по введенным пользователем признакам и фактам.

---

## Технологический стек

*   **Платформа:** .NET 10.0
*   **UI-фреймворк:** WPF (Windows Presentation Foundation), XAML
*   **Язык программирования:** C#
*   **Сериализация:** `System.Text.Json` (с поддержкой кириллицы и форматирования)

---

## Структура проекта

```text
ExpertSysApp/
│
├── Controllers/
│   └── Controller.cs         # Логика логического вывода, работа с JSON и базой правил
├── Models/
│   ├── Rule.cs               # Модель логического правила (Условия -> Заключение)
│   ├── TraceStep.cs          # Шаг трассировки вывода
│   └── TraceStatus.cs        # Статусы выполнения правил (Unmatched, Partial, Success)
├── Views/
│   └── RuleEditorWindow.xaml # Окно редактора базы правил
├── MainWindow.xaml           # Главное окно приложения (Диагностика и трассировка)
└── rules.json                # База знаний по умолчанию
```

## Начало работы и запуск

### Требования
*   Установленная среда **.NET 10.0 SDK** (или выше).
*   Операционная система **Windows** (так как проект использует WPF).

### Инструкция по сборке и запуску

1. Клонируйте репозиторий или распакуйте архив с проектом в удобную папку.
2. Откройте терминал (командную строку) в корневой директории проекта.
3. Выполните команду для сборки проекта:
   ```powershell
   dotnet build
   ```
4. Запустите приложение:
   ```powershell
   dotnet run
   ```

## Как пользоваться экспертной системой

1. **Диагностика:** В поле «Стартовая ситуация» введите известные вам симптомы через запятую (например: `Двигатель=не заводится, Стартер=крутит`).
2. **Трассировка:** Установите галочку «Показать сведения о поиске», чтобы в реальном времени видеть, какие правила активирует система.
3. **Результат:** Нажмите кнопку **«Найти ответ»**, чтобы получить заключение или уточняющие вопросы.
4. **Управление правилами:** Нажмите кнопку **«Редактор базы правил»**, чтобы просмотреть, изменить или дополнить базу диагностических знаний.
